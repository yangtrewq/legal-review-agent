# IdentifyRisk 使用指南（L2 / Prompt 模板）

## 调用前置条件
1. 先通过 `QueryRequirement` 获取合同元数据与附件，确认审查对象；
2. `contract_document` 传入合同正文文本或文档ID；`risk_checklist` 缺省时使用企业默认清单
   （完整清单见资源文件 `risk_checklist.md`，用 read_skill_resource 读取）。

## Prompt 模板（接入真实模型识别时使用）

```
你是企业法务风险识别专家。逐条扫描以下合同内容，基于风险检查清单识别风险点。

# 合同内容
{contract_document}

# 风险检查清单
{risk_checklist}

# 输出要求
对每个风险点输出：clause_location（条款位置）、risk_description（风险描述）、
risk_level（高/中/低）、risk_category（风险类别）、original_text（条款原文，逐字引用不得改写）。
只输出符合契约的 JSON，不要输出其他内容。
```

## 风险定级标准
- **高**：触碰红线条款、无限责任、预付款比例超过基线、单方权利义务严重失衡；
- **中**：偏离基线但有商业惯例支撑、违约责任不对等、管辖约定不利；
- **低**：表述瑕疵、归属约定不明但可补充澄清。

## 输出后动作
- 本技能结果会进入 HITL 卡点，法务人员可能修改风险等级或驳回——被驳回时
  不要原样重试，应检查入参（常见原因：文档不完整、清单类型选错）后再调用；
- original_text 必须逐字引用条款原文，供红线批注定位，不得改写。

## 禁止事项
- 不得在没有合同文档的情况下凭通识编造风险；
- 不得合并多份合同一次性扫描。

# identify_risk_points 使用指南（L2）

## 调用前置条件
1. 必须先完成 `parse_clauses`（条款结构化）与 `fetch_baseline`（基线拉取），把两者的完整 JSON 原样传入；
2. 若会话记忆中存在相对方历史博弈记录（如"对方已两次拒绝违约金上限条款"），在评估风险等级时纳入考量。

## 风险定级标准
- **high**：触碰黑名单条款、无限责任、单方解除权缺失、违约金无上限；
- **medium**：偏离基线但有商业惯例支撑、管辖约定不利；
- **low**：表述瑕疵、与基线措辞差异但实质等价。

## 输出后动作
- 本技能结果会进入 HITL 卡点，法务人员可能修改风险等级或驳回——被驳回时不要原样重试，
  应检查入参（常见原因：条款解析不完整、基线类型选错）后再调用；
- 完整核对清单见资源文件 `risk_checklist.md`（用 read_skill_resource 读取）。

## 禁止事项
- 不得在没有基线 JSON 的情况下凭通识判断风险；
- 不得合并多份合同的条款一次性比对。

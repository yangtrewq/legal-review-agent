# GenerateOpinion 使用指南（L2）

## 调用前置条件
- 只对**已通过 HITL 确认**的风险点出具意见；法务人员在卡点中修改过风险点的，
  以修改后版本作为 `risk_point` 入参；
- 逐个风险点调用（一次一个），不要把整个 risk_points 数组传入；
- 出具意见前可先用 `SearchDocument` 检索相似案例，作为 `reference_cases` 传入。

## suggestion_type 选择规则
- **修改**：条款方向可接受但具体参数偏离基线（如比例、期限、金额）；
- **删除**：触碰红线且无商业必要的条款；
- **新增**：缺失必备保护性条款（如责任上限、保密义务）；
- **妥协**：对方明确拒绝修改且有历史博弈记录时，给出带前提条件的备选方案。

## 输出要求
- suggested_clause 给出可直接替换的完整条款文本；
- reasoning 说明商业与法律双重理由；legal_basis 引用具体法条；
- compromise_option 必填：给出我方可接受的退让边界。

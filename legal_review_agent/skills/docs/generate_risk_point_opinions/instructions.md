# generate_risk_point_opinions 使用指南（L2）

## 调用前置条件
- 只对**已通过 HITL 确认**的风险点生成意见；若法务人员在卡点中修改了风险点内容，
  必须以修改后的版本作为入参。

## 措辞风格（tone）选择
- `standard`：常规商务谈判，默认值；
- `firm`：我方强势/对方多次违约历史时使用；
- `conciliatory`：长期战略合作伙伴、希望尽快成交时使用。
会话记忆中若已记录本交易的谈判立场（facts 中的 stance），优先沿用该立场对应的 tone。

## 输出要求
- 每条意见包含：问题描述、修订建议、可让步的备选方案（如有）；
- 引用基线条款时给出基线原文，便于法务人员直接比对。
